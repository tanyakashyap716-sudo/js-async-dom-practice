# Asynchronous JavaScript & DOM Practice 🚀

A simple, interactive web application built to demonstrate and practice Core JavaScript concepts, specifically Asynchronous operations and dynamic DOM manipulation.

## 🌟 Features
- **Dynamic Interval Updates:** Uses `setInterval` to continuously update a live counter and change the background color of a container with random RGB values every second.
- **Delayed Execution handling:** Uses `setTimeout` to trigger a message exactly 3 seconds after a button click.
- **Bug Fixes applied:** Implemented button disabling during the timeout duration to prevent duplicate element creation and ensure a smooth user experience.
- **Clean Layout:** Designed with a responsive CSS Flexbox layout centered on the viewport.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Transitions)
- Vanilla JavaScript (DOM, Web APIs)
